# Windows 版使用手册

适用于 `dist/WorkBuddyCheckin.exe`。目标机器**不需要 Python、不需要 WorkBuddy 客户端**。

---

## 1. 安装与首次运行

1. 把 `WorkBuddyCheckin.exe` 放到任意目录（桌面、D 盘、U 盘都行）
2. 双击运行
3. 首次启动会在 `%LOCALAPPDATA%\WorkBuddyCheckin` 生成 `config.json`

**配置不写在 exe 旁边**，原因很实际：exe 常被放在桌面或只读目录，
写配置可能被拦；换个位置又像"配置丢了"。写进当前用户的缓存目录后：

- exe 随便挪，配置和令牌都还在；
- 把 exe 发给别人，不会把你的机器人 key 一起带过去；
- 同一台机器的不同用户，各有一份独立配置。

日志第一行会写明当前数据目录，例如：

```
[09:12:01] 程序位置：C:\Users\me\Desktop\WorkBuddyCheckin.exe
[09:12:01] 数据目录（用户缓存目录）：C:\Users\me\AppData\Local\WorkBuddyCheckin
```

### 从旧版升级

v2.x 把 `config.json`、`auth_oauth.json` 写在 exe 旁边。v3.0 首次运行会把它们
**复制**到缓存目录（不删源文件）。确认新版本工作正常后，exe 旁边那两个文件
可以手工删掉，免得下次误以为还在用。

## 2. 账号授权

点「立即授权」→ 窗口里出现一条授权链接 → 复制到手机打开、登录并确认 →
窗口检测到结果后自动关闭。

**链接不绑定设备**：本机浏览器、手机、另一台电脑都行。手机点完确认，本机
这边靠同一个 `state` 轮询到结果，几秒内自动拿到令牌并落盘——手机上不需要
回传任何东西。默认不自动弹本机浏览器；习惯在电脑上操作可以点「在本机打开」。

![授权窗口](../dist/ui_auth.png)

有效期约 28 天，到期前 5 天自动续期。**未授权时界面是锁住的**：
除「立即授权」外，签到、只查状态、设置定时、设置推送全部灰掉：

![未授权](../dist/ui_locked.png)

这样不会出现"点了才报错"的按钮，也不会让人误以为已经配好了。

### 到期提醒

每次签到结束后会看一眼令牌剩余天数：

| 剩余 | 行为 |
|---|---|
| > 2 天 | 什么都不做 |
| ≤ 2 天 | 推一条「授权还剩 N 天」的提醒（说明自动续期没成功） |
| 已过期 | 推「授权已过期，签到会失败」 |

阈值是配置项 `expiry_warn_days`（默认 `2`，设 `0` 关闭），界面不暴露。
不做去重——一天跑两次就发两条，按"每次签到后检查"实现。

### 界面外的授权入口

只在命令行，供排查或迁移用（服务端流程不需要从这里导入，见 [server.md](server.md)）：

```bash
WorkBuddyCheckin.exe --auth                    # 发起授权：打印链接 + 弹本机浏览器
WorkBuddyCheckin.exe --auth --no-browser       # 只打印链接（手机授权 / 无图形环境）
WorkBuddyCheckin.exe --import-token "<导入码>"  # 从另一台机器搬一份令牌
WorkBuddyCheckin.exe --import-token D:\auth_oauth.json
```

> 搬来的令牌要和原机器二选一使用：`refreshToken` 会轮换，两边同时跑会互相踢掉。

## 3. 每日定时

「每日定时」→ 设置触发时间 → **应用到系统**。

![定时](../dist/ui_schedule.png)

| 项 | 说明 |
|---|---|
| 启用 | 勾上才会写入计划任务；取消勾选会删除任务 |
| 时间 | `HH:MM`，可多个（逗号分隔），例如 `09:00, 21:30` |
| 随机抖动 | 0–120 分钟。设 15 表示在 09:00–09:15 之间随机触发 |
| 应用后退出 | 默认开启。定时写好就关掉程序，系统里不留常驻进程 |

系统里生成的任务：

```
任务名    WorkBuddyCheckin
操作      "<exe 绝对路径>" --run
权限      当前用户 + 仅登录时运行 + 普通权限（不弹 UAC）
```

`--run` 是 exe 的无界面入口，跑完即退。**程序不常驻**，也不需要开机启动。

### 任务路径会自动修正

计划任务只认绝对路径。exe 从桌面挪到 D 盘、或者从旧版升级上来以后，
旧路径就失效了。v3.0 起每次打开程序会静默校一次：

- 任务不存在 → 按当前 exe 重新注册；
- 任务指向别的路径 → 改指当前 exe；
- 本来就对 → 什么都不做（只读一次任务定义，约 0.5 毫秒）。

源码运行（`python src/desktop/checkin_gui.py`）**不会**做这件事，避免开发时的注册动作把
用户已装好的 exe 任务抢走。

### 取消

「设置定时」→ **取消定时**。只删计划任务，配置和其它数据都不动。

## 4. 消息推送

「消息推送」→ 设置推送：

| 渠道 | key 填什么 |
|---|---|
| 企业微信 | 群机器人 webhook 里 `key=` 后面那一段（也接受整条链接，会自动抽出 key） |
| 钉钉 | 机器人 webhook 里 `access_token=` 后面那一段 |

只有**勾选**了渠道、并且 key 填对，才会真正推送（"填了 key 但没勾"不会发）。
地址由程序按官方域名拼接，不会把 key 发到别处。

点「发送测试」可以立刻验证链路。

推送内容（桌面版 exe 与服务端 `wb_server.pyz` 用的是同一份文案，
只有「账号」这一行取各自那份令牌里的昵称 + uid）：

```
【WorkBuddy 签到】✅ 签到成功
账号：张三（uid u_123456…）
本次领取：+100 积分
连续签到：1 天｜本期累计：100 积分
时间：2026-10-19 16:50
```

- 签到成功 / 今日已签到 / 活动已结束 / 失败原因（每种都带「账号」行）
- 令牌不可用（损坏 / 未授权）时取不到昵称，这一行会整体省略，不会留空的「账号：」
- 授权到期提醒（见上）

## 5. 配置文件

`%LOCALAPPDATA%\WorkBuddyCheckin\config.json`：

| 键 | 默认 | 说明 |
|---|---|---|
| `push_channels` | `["wecom"]` | 推送渠道，可多个；留空 = 不推送 |
| `wecom_key` | `""` | 企业微信机器人 key |
| `dingtalk_key` | `""` | 钉钉机器人 key |
| `oauth_token_file` | `""` | 令牌路径，留空 = 数据目录下 `auth_oauth.json` |
| `oauth_auth_timeout` | `300` | 等授权的秒数（手机操作也够） |
| `expiry_warn_days` | `2` | 剩余多少天时提醒，`0` 关闭 |
| `schedule_enabled` | `false` | 是否已写入计划任务（界面维护） |
| `schedule_times` | `["09:00"]` | 触发时间 |
| `schedule_jitter` | `15` | 随机抖动分钟数 |
| `exit_after_apply` | `true` | 应用定时后自动退出 |

> 改配置建议走界面，避免手写 JSON 时把 key 弄坏。程序只改它认识的那几个键，
> 不会整份重写。

## 6. 命令行与退出码

| 参数 | 作用 |
|---|---|
| `--run` | 无界面签到一次（计划任务用的就是它） |
| `--check-only` | 只查状态，不领 |
| `--auth` | 发起授权（打印链接并等待） |
| `--no-browser` | 配合 `--auth`：不自动打开本机浏览器 |
| `--import-token <码或文件>` | 导入令牌（迁移 / 救急） |
| `--test-notify` | 发一条测试消息 |
| `--selftest` | 环境自检，结果写 `selftest.json` |
| `--diagnose` | 授权 + 接口连通性（不打印令牌） |
| `--sched-status` | 查看计划任务，含"是否指向当前程序" |
| `--version` | 版本 / 运行方式 / 数据目录 |
| `--json` | 输出单行 JSON（可与上面组合） |

| 退出码 | 含义 | 要不要管 |
|---|---|---|
| `0` | 成功（含"今天已签到"） | 不用 |
| `1` | 网络 / 接口失败 | 看日志 |
| `2` | 环境问题：未授权、令牌失效、推送没配好 | 按提示处理 |
| `3` | 网络 / 授权协议异常 | 看日志 |
| `267011` 等 | 计划任务自身状态（尚未运行过等） | **不是失败** |

## 7. 备份与迁移

要换机器 / 重装系统时，拷走整个 `%LOCALAPPDATA%\WorkBuddyCheckin` 目录即可
（`config.json` + `auth_oauth.json`）。到新机器上：

1. 把 exe 放好，先运行一次让它建好缓存目录（或手工创建同名目录）
2. 把两个文件放进数据目录
3. 打开程序确认授权状态正常，再「应用定时」
4. **把旧机器上的定时取消**，避免两边都跑

只想带走令牌、不带配置：`--import-token` 那条路。
